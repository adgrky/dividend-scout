# 自動更新の設定について

**ここのファイルを手で触る必要はありません。**

自動更新のオン／オフは、プロジェクト直下の **`自動更新の設定.command`** を
ダブルクリックして切り替えます。設定ファイルはそのとき自動で作られ、
オフにすると消えます。

## 中で何が起きているか

オンにすると `~/Library/LaunchAgents/com.ken.diva.weekly.plist` が
1つ置かれ、Mac に「毎週土曜9時に `scripts/scheduled_update.py` を走らせて」と
伝えます。オフにすると、そのファイルを外して消します。他のアプリには影響しません。

`scheduled_update.py` は、走るたびに「何が何日前か」を見て、古いものだけやります。

| | 中身 | 時間 | 発動条件 |
|---|---|---|---|
| 毎週 | 株価・配当・スコア | 約10分 | 毎回 |
| 月1回 | 会社の基本情報 | ＋約10分 | 前回から30日 |
| 年1回 | 有価証券報告書 | ＋約70分 | 前回から180日 かつ 7月以降 |

しきい値は `config.yaml` の `schedule:` で変えられます。

## このフォルダに残っている古いファイル

`com.ken.diva.weekly.plist` と `com.ken.diva.daily.plist` は、
`自動更新の設定.command` を作る前の手書きの見本です。**いまは使っていません。**
daily のほうは ntfy 通知を前提にしていますが、通知は使わない方針になりました。
